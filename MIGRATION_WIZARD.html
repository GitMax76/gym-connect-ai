1. Crea il Progetto Firebase

Per iniziare, dobbiamo creare un progetto gratuito sulla console di Google Firebase ed attivare i servizi base.

  • Accedi a Firebase Console

    Vai su console.firebase.google.com ed esegui il login con il tuo account Google.

  • Crea un Nuovo Progetto

    Clicca su "Aggiungi progetto", assegna il nome gym-connect-ai (o simile) e clicca su continua. Puoi disattivare Google Analytics per velocizzare.

  • Attiva Firestore Database

    Nel menu a sinistra, clicca su "Build > Firestore Database". Clicca su "Crea database", scegli la posizione dei server (consigliato eur3 per l'Europa) ed avvialo in Modalità Test.

  • Attiva Firebase Authentication

    Fai clic su "Build > Authentication" e poi su "Inizia". Nella scheda "Sign-in method", seleziona Email/Password e abilitalo.

  • Attiva Cloud Storage

    Nel menu, vai su "Build > Storage", fai clic su "Inizia", procedi con le impostazioni standard e fai clic su "Fine". Ti servirà per salvare i file e gli avatar.

2. Ottieni le Chiavi API

Dobbiamo registrare un'applicazione web nel progetto Firebase per ottenere le chiavi API da agganciare alla webapp.

  • Registra un'app Web

    Dalla dashboard principale di Firebase, fai clic sull'icona Web (</>) al centro dello schermo.

  • Assegna un Nickname

    Immetti il nome GymConnect Web. Seleziona l'opzione per configurare anche Firebase Hosting e fai clic su "Registra l'app".

  • Copia la Configurazione

    Cerca l'oggetto `firebaseConfig` generato automaticamente. Copia i singoli valori (apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId). Li useremo nel prossimo passaggio.

3. Configura l'Ambiente Locale

Inserisci le chiavi ottenute nel file delle configurazioni locali del tuo progetto.

Crea o apri il file denominato .env nella cartella principale del progetto ed inserisci le chiavi compilate con i tuoi valori di Firebase.
File: .env 
VITE_FIREBASE_API_KEY=inserisci_qui_la_tua_api_key
VITE_FIREBASE_AUTH_DOMAIN=inserisci_qui_auth_domain
VITE_FIREBASE_PROJECT_ID=inserisci_qui_project_id
VITE_FIREBASE_STORAGE_BUCKET=inserisci_qui_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=inserisci_qui_sender_id
VITE_FIREBASE_APP_ID=inserisci_qui_app_id

  • Configurato .env

    Ho creato/modificato il file `.env` con le mie chiavi di Firebase corrette.

4. Verifica & Regole di Sicurezza

Carica il tuo file .env per testare la connessione al database Firestore in tempo reale dal browser!

📁 Trascina qui il tuo file .env o clicca per cercarlo Verrà letto solo localmente per eseguire il test di connessione.
Stato Test Connessione:
  • ? File .env caricato ed analizzato
  • ? Validazione Chiave API Firebase
  • ? Scrittura documento di prova su Firestore
  • ? Lettura e pulizia documento da Firestore
Incolla queste Regole su Cloud Firestore: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null || true; // Per testing iniziale
    }
  }
}

  • Regole configurate & Test superato

    Le regole sono state caricate su Firebase ed il test di connessione in tempo reale è andato a buon fine.

5. Deploy dell'App su Firebase Hosting

Adesso sei pronto per compilare ed inviare il progetto direttamente sui server di Google.

Terminale / Riga di Comando 
# 1. Installa lo strumento CLI di Firebase globalmente sul tuo PC
npm install -g firebase-tools

# 2. Esegui il login nel terminale con il tuo account Google
firebase login

# 3. Costruisci i file ottimizzati per la produzione
npm run build

# 4. Spedisci il progetto sul Cloud di Firebase!
firebase deploy --only hosting

  • Deploy completato!

    Ho eseguito i comandi nel terminale e visualizzo il link del sito online (es. https://gym-connect-ai.web.app).
